# C. Automated Visual Data Report

### Data Analytics & Visual Report

#### Dataset Focus: Davao Region Renewable Energy Production Index (Mock CSV Analysis)

#### 1. Data Cleaning Protocol Log
**Raw Input Problem:** The CSV dataset contained missing energy production values for several municipalities in 2023, duplicate entries from provincial reporting offices, and inconsistent measurement units (MWh and kWh).

**AI Cleaning Instruction:** "Scan the renewable energy dataset. Remove duplicate records based on Municipality and Year. Replace null values in the Energy_Production column using the median value from neighboring years. Convert all kWh measurements into MWh. Output a standardized dataset ready for visualization."

**Result:** Successfully normalized 150 records across Davao Region municipalities from 2020–2025.

#### 3. Human Analytical Narrative (The "Why" Factor)

The visualizations show a steady increase in renewable energy production in the Davao Region from 2020 to 2025, likely driven by investments in solar, micro-hydropower, and rural electrification projects. At the same time, fossil fuel dependence declined, improving energy security and reducing vulnerability to fuel price fluctuations. These trends highlight the need for continued support for renewable energy infrastructure to promote sustainable development and climate resilience across Mindanao.
